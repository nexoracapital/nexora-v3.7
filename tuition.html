🎓 Nexora Tuition Academy

Firestore-based tuition system for teachers and students. Teachers can create profiles, add multiple subjects, share notes and class links. Students can find teachers, send requests and manage learning records.

🔐 Tuition Academy Login

Select your role. Teacher and Student dashboards use Gmail login. No localStorage is used.

👨‍🏫 Teacher Login

Create or manage teacher profile, multiple subjects, fee, online classes, notes, wallet and support.

👨‍🎓 Student Login

Find teachers, send tuition requests, view class links, notes, wallet and support records.
