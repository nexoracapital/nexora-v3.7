✅ School OS Professional Workflow

This system is designed so that every role works in its own clean dashboard. The School Manager controls school records, teachers manage assigned classes, students view their own academic progress, Tuition Academy handles public teacher profiles, and Online Classes connect teachers with students through trusted meeting platforms.

🏫 Principal / Manager
Create classes, register teachers, assign subjects, approve students, manage exams, results, attendance, online class access and reports.
👨‍🏫 Teacher
Register assigned class students, mark daily attendance, create tests, upload notes, assign homework and schedule online classes.
👨‍🎓 Student
View attendance, join online class, attempt tests, view results, read notes, receive teacher feedback and track learning progress.
